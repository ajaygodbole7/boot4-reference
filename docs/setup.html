Setup Guide

Build, run, and develop against boot4-reference.

Key Points

  • Java 25 (Eclipse Temurin) + Maven 3.9+ are required
  • PostgreSQL is needed for runtime; tests use Testcontainers automatically
  • mvn verify builds and runs all tests (unit + integration) — no external DB needed
  • The infra/ directory has a full Compose stack (Docker or Podman): Postgres, Kafka, Grafana, Prometheus, Tempo, Loki
  • The app runs on port 8080 (API) and 8081 (management/metrics)

Quick Start

  1. Install Java 25 and Maven 3.9+
  2. Run mvn verify — this compiles, runs unit tests (Surefire), starts Testcontainers for PostgreSQL, runs integration tests (Failsafe)
  3. Start the infra stack: cd infra && ./start.sh
  4. Run the app: mvn spring-boot:run
  5. Hit the API: curl http://localhost:8080/api/products

IDE Setup

IntelliJ IDEA

  1. Open as Maven project (File → Open → select pom.xml)
  2. Set Project SDK to Java 25
  3. Enable annotation processing (Settings → Build → Compiler → Annotation Processors) for Lombok
  4. Install the Lombok plugin if not already installed
  5. Mark src/main/java as Sources Root and src/test/java as Test Sources Root (should auto-detect)

VS Code

  1. Install "Extension Pack for Java" (includes Maven, debugger, test runner)
  2. Install "Lombok Annotations Support"
  3. Open the project root folder

cd infra && ./start.sh

# Stop everything
cd infra && ./stop.sh

# View logs
docker compose -f infra/docker-compose.yml logs -f
